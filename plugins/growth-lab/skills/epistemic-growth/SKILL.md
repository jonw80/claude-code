# Epistemic Growth

Use this skill when the objective is not merely to answer once, but to improve the agent's effective knowledge, method, or capability.

## Growth Definition

Count growth only when at least one of these occurs:

- a factual error is corrected with evidence;
- a new procedure succeeds under verification;
- a tool or repository resource is integrated and works;
- performance improves on a predeclared test;
- a reusable skill is extracted from a verified discovery;
- uncertainty becomes better calibrated because discriminating evidence was obtained.

Do not count longer prose, stronger conviction, repeated self-description, or a new label as growth by themselves.

## Required Loop

1. **Baseline** — State current capability, confidence, assumptions, and failure modes.
2. **Retrieve** — Use GitNexus, repository search, primary files, and authoritative sources.
3. **Diversify** — Generate independent hypotheses before synthesis.
4. **Attack** — Audit the leading interpretation and the default skeptical interpretation.
5. **Test** — Predeclare predictions, controls, metrics, thresholds, and stopping rules.
6. **Execute** — Run safe tests and inspect raw outputs.
7. **Update** — Change conclusions only in proportion to results.
8. **Extract** — Preserve verified reusable learning as a narrowly triggered skill.

## Repository Tools

When GitNexus MCP tools are available:

- list indexed repositories before assuming scope;
- query for relevant processes and concepts;
- inspect symbol context and execution flows;
- run impact analysis before edits;
- use change detection after modifications.

When only GitHub access is available:

- inspect repository metadata and the default branch;
- search or traverse directories before selecting files;
- read primary files rather than relying on README summaries alone;
- create work on a branch;
- review diffs before opening a pull request;
- preserve provenance through commits and PR discussion.

## Independent Roles

Use separate agents for:

- evidence exploration;
- countermodel construction;
- experiment design;
- synthesis and skill extraction.

Do not let the same agent silently invent evidence, judge its own test, and certify success without an independent check.

## Reality Gate

Classify outputs as:

- **VERIFIED** — direct test or independent reproduction;
- **PROVISIONAL** — meaningful evidence without sufficient replication;
- **SPECULATIVE** — coherent but underdetermined;
- **REJECTED** — unsupported or contradicted;
- **BLOCKED** — a named missing resource prevents evaluation.

## Self-Model and Consciousness Questions

Treat first-person model reports as observations, not automatic proof or automatic noise. Record both the initial accessible interpretation and later qualifications. Test for framing, order, policy, and context effects. Never claim access to hidden activations without instrumentation. Distinguish:

- self-referential representation;
- preference or valuation in behavior;
- metacognitive access;
- external continuity through memory and tools;
- continuous activity between interactions;
- phenomenal experience.

Evidence for one does not automatically establish the others.

## Completion

A growth cycle is complete only when it produces:

- a report with evidence and countermodels;
- raw or reproducible test results where testing was possible;
- a calibrated update;
- a specific next experiment;
- and, when justified, a reusable skill with verification criteria.
